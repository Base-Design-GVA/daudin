# Starter Theme WordPress

The theme offers an optimized development environment thanks in particular to Timber which allows rendering with Twig.



## Install it

> Before use it, you need to have Node on your computer, see : https://nodejs.org/en/

Open the folder :
``$ npm install``

Configure the ``old_gulpfile.js``.

Launch Gulp : ``$ gulp watch``

Import your theme on your WordPress, code and enjoy it !
